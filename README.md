# После дождя

Авторская образовательная игра: находите слова нужной категории, чтобы ливень постепенно стихал. После последнего ответа персонаж останавливается, выглядывает солнце и появляется кнопка «ДАЛЬШЕ».

## Запуск

Игра не требует сборки или сервера приложений. Для локального просмотра запустите `python3 -m http.server 8000` в корне и откройте `http://localhost:8000`. Не открывайте `index.html` через `file://`: используются JavaScript-модули.

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**. Ожидаемый адрес: https://propodgotovkaa-creator.github.io/dojdi/

## Встраивание в Genially

Вставьте iframe после включения GitHub Pages:

```html
<iframe src="https://propodgotovkaa-creator.github.io/dojdi/" title="После дождя" width="960" height="540" style="border:0;aspect-ratio:16/9" allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Звук включается только после первого действия пользователя. Игру можно пройти без звука. Пауза останавливает движение и звук. При скрытии вкладки анимация не продвигается.

## Структура

- `js/rounds.js` — 11 тем, пять правильных и семь отвлекающих слов в каждой.
- `js/game.js` — карточки, переходы, пауза, загрузка изображений и масштабирование 16:9.
- `js/scene.js` — погода, транспорт, финальные реакции и чередование персонажей.
- `js/gait.js` — отрисовка нового героя по захваченным движениям CMU; данные в js/walk-data.js, источник в motion-source.md.
- `js/audio.js` — звук с управлением громкостью дождя.
- `assets/images` — исходные PNG сцены, облаков и транспорта без повторного сжатия; атласы героев с прозрачностью. Старые WebP сохранены для истории.
- `assets/audio` — оригинальные синтезированные WAV: дождь, тихий транспорт, ответы, мелодия и птицы.
- `js/resolution.js` — физическое разрешение canvas с учётом плотности экрана и масштаба окна; герои рисуются напрямую без уменьшенной промежуточной картинки.
- `styles.css` — панель, рамки карточек и компоновка.

Девушка появляется в заданиях 1, 3, 5 и далее; парень — в 2, 4, 6 и далее. Мама и ребёнок исключены. В городе по очереди ездят красная машина и бирюзовый автобус. После всех заданий появляется дополнительная радуга и кнопка «ИГРАТЬ СНОВА».

## Проверки

Node.js 20 или новее: `npm test` (внешние зависимости не нужны).

Графика подготовлена генерацией. Новая версия героев и походки доступна отдельно в walk-preview.html; описание и запрос генерации — hero-design.md. Звуки синтезированы для этой игры. Изображение с Magnific служило только художественным ориентиром и в файлы игры не включено.

Текущая версия включает перерисованных героев и анимацию ходьбы на основе захвата реальных движений. Стиль и характер движения можно уточнять по обратной связи.
